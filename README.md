# pa-permission-self-reviewer
Automates permission reviews by generating reports that highlight potential risks and inconsistencies based on organizational policies and best practices. Provides actionable recommendations for permission adjustments. - Focused on Tools for analyzing and assessing file system permissions

## Install
`git clone https://github.com/ShadowStrikeHQ/pa-permission-self-reviewer`

## Usage
`./pa-permission-self-reviewer [params]`

## Parameters
- `-h`: Show help message and exit
- `--path`: The path to the directory or file to analyze.
- `--config`: Path to the configuration file. Defaults to config.json
- `--report`: Path to the report file. Defaults to permission_report.txt
